1. pip install exponent-server-sdk

2. settings.py -> INSTALLED_APPS:
   INSTALLED_APPS = [
       ...
       "notifications",
   ]

3. project urls.py:
   urlpatterns = [
       ...
       path("notifications/", include("notifications.urls")),
   ]

4. python manage.py makemigrations notifications
   python manage.py migrate

Endpoints exposed:
   POST   /notifications/push-token/          register a device's Expo push token
   DELETE /notifications/push-token/          unregister (call on logout)
   GET    /notifications/                     paginated list, newest first
   GET    /notifications/unread-count/        { "count": n }
   POST   /notifications/mark-all-read/
   POST   /notifications/<id>/mark-read/
